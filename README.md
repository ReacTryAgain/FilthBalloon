# :balloon: Trash Hunt:
북한의 오물풍선이 대한민국 상공으로 날아오면서 발생하는 환경 오염, 감염병 위험, 그리고 잠재적인 생화학적 위협에 대응하기 위해, TrashHunt 프로젝트는 다음과 같은 목표와 방향성을 갖고 개발됩니다:

생화학 무기 감지 및 경고 시스템:

오물풍선에 포함될 수 있는 생화학적 물질과 유해 물질을 효과적으로 탐지하고 경고할 수 있는 고도화된 기술을 개발합니다.
실시간 감지 및 추적 기능을 통해 위협적인 오물풍선의 경로를 모니터링하고, 신속하게 대응할 수 있는 인프라를 구축합니다.

국민 안전 교육 및 경각심 고취:

국민들이 오물풍선의 위험성을 충분히 이해하고, 발견 시 적절한 행동을 할 수 있도록 교육과 홍보를 강화합니다.

TrashHunt는 이러한 목표를 바탕으로, 북한의 오물풍선이 초래할 수 있는 환경적, 보건적, 안보적 위협에 대한 통합적인 대응 시스템을 구축하는 것을 목표로 합니다. 이를 통해 대한민국 국민의 안전을 보장하고, 국가 안보를 강화하며, 환경 오염을 최소화하는 지속 가능한 해결책을 마련하고자 합니다.


<br/>

## 👉🏻 주요 기능
- 오물풍선 제보 기능 : 오물풍선의 발견 위치, 시각, 상세 정보, 사진을 여러 사람들과 공유하기 위해 제보할 수 있습니다.
- 오물풍선 타임라인 기능 : 제보된 오물풍선에 관련한 정보들을 확인할 수 있습니다.
- 카카오 API 지도 맵 : 제보된 오물풍선의 위치를 지도에 표시함으로써 직관적으로 확인할 수 있습니다.
- 오물풍선 피하기 게임 : 저희 오물풍선 웹 서비스에 대한 관심을 가질 수 있고 위험성을 인지할 수 있습니다.

<br/>

## 👉🏻 실행 방법
1. vscode에 FilthBalloon 폴더 불러오기
2. npm install
3. npm start
